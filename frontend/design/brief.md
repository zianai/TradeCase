# TradeCase 工作台设计简报

- 受众：每日处理外贸询盘、调查证据和人工审核的销售及主管。
- 核心任务：导入询盘 → 查证 → 审核草稿 → 人工跟进。
- 气质：清楚、审慎、专注；避免炫技、聊天平台式交互。
- 首屏主行动：导入询盘；Case 页主行动随状态转为开始调查或查看待审核项。
- 范围：新建 GUI 的信息架构、布局与视觉；保留已有业务规则和 API 为真相。
- 非交互选择：深色导航、暖纸内容、墨绿主色、少量赭色强调，数据以行列和证据关联呈现。暂定方向，不声明人工设计批准。

## 覆盖的 Skill 默认

用户要求持续实施并完成端到端验收，且未提供视觉基线。采用 Skill 的非交互路径，在独立分支继续实现；不增加视觉确认阻塞。可用性和审批准确性优先于展示型页面的字号跳跃、纹理和动画。
