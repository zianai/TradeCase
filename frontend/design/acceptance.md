1. 合成询盘导入、元数据版本修改、调查、查看来源快照、审批、友好语气预览、保存编辑草稿导致旧审批失效、再次审批、创建/完成跟进、JSON 导出、刷新恢复及 390px 窄屏检查。实际 Case 和步骤保存在 [browser-e2e.json](rounds/01/browser-e2e.json)。
2. 内部知识创建 v1、修订 v2、查看 v1 原文；资料保持用户提供且未核实，未作为在线证据。
3. 人工提交自撰合成快照和逐字引文；显示未执行在线抓取；人工复核初始来源许可与角色确认均为 false。测试明确以审核员身份确认自撰资料的权限，仍保留 unverified/other 及 UNKNOWN 主张，现行官方规则确认未勾选，保存人工复核版本。

另外九个测试使用受控 API 响应，验证空状态和键盘操作、来源文本不能执行外发、拒绝/要求修改/要求补证据携带精确 hash 与版本、切换租户凭据时丢弃前一租户迟到响应，以及三种语气逐字保留价格/未知交期/未核实认证/签名、取消编辑恢复原文、审核员只能取消待执行动作并携带原因与当前版本、只读角色不显示取消控件。取消操作的 UI 测试使用模拟 API；真实后端权限和状态保护由系统级测试覆盖。

浏览器测试不调用发送接口，真实 API 场景确认 outbox 为空。截图位于 [rounds/01](rounds/01/)，包含桌面、手机、快照、草稿审批、知识历史、人工来源复核与未保存语气预览。

## 验证范围与限制

- 本地浏览器流程不证明真实模型、网络抓取、付费来源、邮件服务或 CRM 在线成功；这些外部能力没有在本轮启用。
- 人工复核浏览器场景验证了安全默认值及版本保存，没有将合成内容升级为可信事实，也未验证真实业务人工判断的正确性。
- 静态审计针对实际 DOM 快照；四项警告来自两个视口的未完全抽取颜色 token 与 4px 栅格外间距。交互由上述 Playwright 测试独立覆盖。
- 桌面和手机截图已经独立 Agent 复核；视觉方向仍为 AI 暂定，不代表用户完成设计验收。
- 凭据仅在测试进程与浏览器会话中使用；Playwright trace 关闭，报告未保存令牌。
