# 设计决策

2026-10-28：暂定（AI 选择）工具型工作台方向。深色固定导航与暖纸工作区隔开功能层级，墨绿为可执行主操作，赭色用于人工待办。未沿用通用聊天布局：以 Case、原始证据、草稿版本和审批范围为核心。审批可见 hash/版本/范围，拒绝与要求补证据独立存在。所有视觉结果仍需实际浏览器检查；无人工批准基线。

受众工作语言为中文，商务回复为英文；公开来源内容保持原文。所有事实、推断、未知分别标记。未连接的服务与合成演示明确展示；不填充虚构业务指标。

2026-10-28 验证轮次：第一轮确定性检查发现次要文字对比度不足、导航可访问名称不包含英文可见标签，以及静态导出遗留开发预加载链接；第二轮仅剩品牌名称匹配问题；第三轮 `design/rounds/03/audit/report.md` 为 fail 0。对比度、横向溢出、裁切、焦点和 axe 检查通过。仍有色值未完全抽为 token 与细节间距不在 4px 栅格的警告；不将这两项警告等同于功能失败。审计针对实际浏览器 DOM 的静态快照，交互行为另由 Playwright 真实端到端测试验证。

独立父 Agent 阅读第一轮实际桌面/手机截图，认为层级清楚且无横向溢出，并要求将 draft_review/mail_send/crm_sync 译为业务用语；已落实。此为独立 Agent 的评审，不是用户设计批准。新的用户审批基线仍未建立。
